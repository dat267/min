# `cmd add --group` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `--group` flag to `min cmd add` so users can create a command group (empty struct, no `Run` method) and later add leaf commands under it.

**Architecture:** Thread a `group bool` through `CmdAddCmd` → `scaffold.AddCommand`. When set, the final path segment is created as a group (no `Run` method) instead of a leaf, and its help text defaults to `"<name> command group"`. All existing find/append/register logic is reused.

**Tech Stack:** Go 1.26, Kong (github.com/alecthomas/kong v1.16.0).

## Global Constraints

- Without `--group`, behavior is byte-for-byte unchanged; the existing `TestCmdAddCmd_SubgroupUnderLeafCommand` must still pass.
- The flag name is `--group` (Kong derives it from the `Group` field; no short flag).
- `scaffold.AddCommand` signature changes to `(name, desc string, group bool) error`.
- When `--group` targets a name that already exists as a leaf, the error is `cannot add group %q: %s is already a leaf command`.
- Adding an existing group again is a silent no-op.
- Must pass `go build ./...`, `go vet ./...`, `go test -race -count=1 ./...`, and `golangci-lint run ./...`.

```go
type CmdAddCmd struct {
	Name  string `help:"Command name (use dots for nesting, e.g. admin.users.create)" arg:""`
	Desc  string `help:"Description for the command"`
	Group bool   `help:"Create a command group instead of a leaf command"`
}

func (c *CmdAddCmd) Run() error {
	return scaffold.AddCommand(c.Name, c.Desc, c.Group)
}
```

- [ ] **Step 4: Update `scaffold.AddCommand`**

`internal/scaffold/scaffold.go`:

1. Signature: `func AddCommand(name, desc string, group bool) error`.
2. Default help for the final segment:
   ```go
   helpText := desc
   leaf := segments[len(segments)-1]
   if helpText == "" {
       if group {
           helpText = leaf + " command group"
       } else {
           helpText = leaf + " command"
       }
   }
   ```
3. In the loop, replace the `isLeaf` computation and the leaf error:
   ```go
   for i, seg := range segments {
       isFinal := i == len(segments)-1
       isLeaf := isFinal && !group
       fieldName := naming.SanitizeFieldName(seg)
       structName := fieldName + "Cmd"
       ```
4. Replace the `exists` block's leaf error:
   ```go
   if exists {
       if isLeaf {
           return fmt.Errorf("command %q already exists in %s", name, targetFile)
       }
       if StructHasMethod(targetFile, structName, "Run") {
           if group {
               return fmt.Errorf("cannot add group %q: %s is already a leaf command", name, structName)
           }
           return fmt.Errorf("cannot add subcommands under %q: %s is already a leaf command", seg, structName)
       }
   }
   ```
5. Replace the per-segment help block (so the final group keeps `helpText`):
   ```go
   segHelp := helpText
   if !isFinal {
       segHelp = seg + " command group"
   }
   ```

The rest of the loop (append/register, `currentFile`/`currentStruct` updates) is unchanged.
